HeroSiege Offline Tool - S10 · v2.7.12
A Windows desktop editor for Hero Siege offline saves, created by shift.

Features
- Item editor: Generate equipment, runes, gems, jewels, charms, keys, relics, and crafting materials.
- Batch generation: Create multiple copies with unique roll seeds, or generate complete key and relic sets.
- Vault interface: View stash contents, preview placement, and stage supported item moves, cloning, rerolls, and deletions.
- Character editor: Edit character attributes, progression, professions, skills, and supported quest objectives.
- Storage controls: Choose character-owned storage and manually configure visible DLC tabs.
- Artwork: Automatically downloads 1,243 verified item images in the background, with pause/resume and offline caching.
- Save safeguards: Staged changes, review before saving, automatic backups, conflict checks, and backup restoration.

Installation
1. Download the Windows release ZIP.
2. Right-click → Extract All.
3. Run HSOfflineLootForge.exe.
No programming tools required. Internet access is needed to download uncached artwork.

Important notes
- Offline characters only. Close Hero Siege and Easy Anti-Cheat before editing saves.
- Keep an independent backup of your original saves.
- Stat previews show catalog ranges—not exact seed-generated rolls. Individual stat-roll customization is not currently supported.
- 183 catalog entries still lack verified artwork and display fallback icons.
- Quest editing is build-dependent and limited to supported operations.
- Storage ownership settings only control visibility; they do not unlock DLC.
